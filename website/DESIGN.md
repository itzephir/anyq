# anyq landing

Лендинг наследует утверждённую визуальную основу itzephir: IBM Plex Sans/Mono,
нейтральные поверхности, тонкие границы, приглушённый синий акцент и обе темы.
Семантические цвета соответствуют portfolio Workspace. Шрифты локальные;
лицензии находятся в assets/licenses.

Композиция продукта самостоятельна: компактная навигация, объяснение допуска
рядом с наглядной очередью, реальный CLI workflow и установщики.
Иллюстрация очереди — семантический HTML/CSS с текстовым объяснением.
У портфолио не заимствуются webring, вкладки и размеры общего header.

По выбору пользователя убраны английские надзаголовки, повторное пояснение hero,
подпись про SQLite, строка свойств и три карточки принципов. Установка содержит
команды без описания реализации, ссылок на checksums и служебного статуса релиза.
Подробности владения и установки остаются в документации CLI.

Основная ширина 1120 px. На 800 px колонки складываются; от 320 px содержание
остаётся доступным. Текст команд выделяется и копируется. Обе команды доступны
через native details даже без JavaScript. JS добавляет сохранение темы и copy;
ссылки и содержимое остаются обычным HTML. URL ?theme=dark/light выбирает тему
для проверки и OpenDesign. Тема по умолчанию следует системной настройке.

OpenDesign использует тот же собранный HTML и отдельный проект с библиотекой
user:itzephir. Исправления в макете следует переносить обратно в website/.
