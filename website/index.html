All commands ↗
example.shbash / zsh 
# Set up shared resources
anyq topic create build -c 2
anyq topic create emulator

# Wait for admission to all topics
anyq task create build-01 -t build -t emulator -w

# Run your work
npm run build

# Release all task resources
anyq task complete build-01
i

Windows PowerShell
Windows x64 · PowerShell 5.1+

Installs to %ProgramFiles%\anyq for all users. Restart your terminal afterward.
