Все команды ↗
example.shbash / zsh
# Подготовьте общие ресурсы
anyq topic create build -c 2
anyq topic create emulator

# Дождитесь допуска ко всем топикам
anyq task create build-01 -t build -t emulator -w

# Выполните свою работу
npm run build

# Освободите все ресурсы задачи
anyq task complete build-01
i

Задайте уникальное имя для каждого запуска.
Все участники используют одну локальную базу.

ATOMIC

Все ресурсы сразу

Задача занимает по одному слоту каждого топика. Частичного захвата нет.

ORDERED

Общий порядок

Одна последовательность регистрации для всех топиков. Очередь сохраняется на диске.

EXPLICIT

До вашего complete

Выход из wait и авария процесса не освобождают слоты. Завершение всегда явное.

Релизы и SHA-256 ↗
macOS / Linux sh
Apple Silicon, Intel · Linux ARM64, x64
curl -fsSL https://anyq.itzephir.com/install.sh -o install-anyq && chmod +x install-anyq && ./install-anyq

Установка в ~/.local/bin. Скрипт подскажет, как добавить каталог в PATH.

Windows PowerShell
Windows x64 · PowerShell 5.1+
curl.exe -fL https://anyq.itzephir.com/install.ps1 -o install-anyq.ps1; if ($?) { powershell -NoProfile -ExecutionPolicy Bypass -File .\install-anyq.ps1 }

Установка в %LOCALAPPDATA%\anyq\bin. PATH обновляется для пользователя; откройте новый терминал.

ОС и архитектура определяются автоматически. Перед установкой проверяется SHA-256 архива. Посмотреть скрипты.

Бинарная установка доступна после публикации первого релиза. До этого — сборка из исходников.

ПОД ВАШИМ КОНТРОЛЕМ

Нет таймаутов и heartbeat. После сбоя проверьте задачу через anyq task NAME и завершите её явно. Для отмены задачи до запуска — anyq task complete NAME --force.
