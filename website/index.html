anyq управляет допуском.
Работу запускаете вы.

Все команды ↗
example.shbash / zsh 
# Подготовьте общие ресурсы
anyq topic create build -c 2
anyq topic create emulator

# Дождитесь допуска ко всем топикам
anyq task create build-01 -t build -t emulator -w

# Выполните свою работу
npm run build

# Освободите все ресурсы задачи
anyq task complete build-01
i

Задайте уникальное имя для каждого запуска.
Все участники используют одну локальную базу.

Пара команд.
И можно в очередь.

macOS / Linux sh
Apple Silicon, Intel · Linux ARM64, x64 
curl -fsSL https://anyq.itzephir.com/install.sh -o install-anyq && chmod +x install-anyq && ./install-anyq

Установка в /usr/local/bin. При необходимости скрипт запросит sudo.

Windows PowerShell
Windows x64 · PowerShell 5.1+ 
curl.exe -fL https://anyq.itzephir.com/install.ps1 -o install-anyq.ps1; if ($?) { powershell -NoProfile -ExecutionPolicy Bypass -File .\install-anyq.ps1 }

Установка в %ProgramFiles%\anyq для всех пользователей. После установки перезапустите терминал.
